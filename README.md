# 🚀 FlowPilot — AI-Powered Workspace & Priority Management Platform

> **Acdyon Technologies Frontend Challenge Submission (Part 2 — The Premium Home Page)**

FlowPilot is a modern, high-performance SaaS landing page built for AI workload balancing, priority management, and team capacity tracking.

---

## ✨ Features & Highlights

- **⚡ Lightning-Fast Performance**: Built with React 19, Vite, and Tailwind CSS v4.
- **🎨 Premium Dark Theme**: Custom true-black (`#09090b`) and dark zinc (`#121215`) aesthetic with electric indigo accents.
- **✦ Interactive Product Showcase**: Real-time **AI Auto-Balance** demo simulating workload rebalancing across engineering and design teams.
- **🧭 Smart Auto-Hiding Navbar**: Sleek glass navigation header that automatically hides on scroll down and reappears on scroll up.
- **📱 100% Responsive**: Tailored for all devices from 390px mobile screens to 1440px+ desktop displays.
- **🛡️ Honest Copy**: Built in strict adherence to the challenge rules (0 fake testimonials, 0 fake user numbers).
- **🎁 Hidden Easter Egg**: Click the **Acme Product** logo 5 times in the interactive dashboard preview to unlock Secret Mode.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Icons**: Lucide Icons
- **Deployment**: Static Bundle Ready (`dist/`)

---

## 🚀 Local Development Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Aditya-kumar2004/Acdyon_Technologies.git
   cd Acdyon_Technologies
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```
